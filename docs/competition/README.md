## 写作原则

1. 只陈述代码、数据库、文件和浏览器已验证的事实。
2. 将“已实现”“部分实现”“演示数据”“规划中”明确分开。
3. 不在用户界面展示内部画像版本、证据计数、置信度、模型名、运行编号或原始思维链；这些信息仅保留在后台审计与答辩材料中。
4. 所有关键结论尽量绑定测试、截图、数据库记录、下载文件或运行日志。
