# 学生端无障碍、键盘与响应式深度审计

日期：2026-07-14
范围：学生端主路径；屏幕阅读器语义、键盘全流程、色觉差异、200% 等效重排、移动端断点、减少动态效果。
环境：本地真实前后端 `127.0.0.1:5174` / `127.0.0.1:8001`，学生账号登录态，Chromium + Playwright。

> 本报告是工程审计与修复决策依据，不构成 WCAG 或其他无障碍标准的合规认证。自动规则、可访问性树、键盘遍历和视觉检查需要结合判断；组件内部节点产生的误报已单独标注。

屏幕阅读器覆盖采用 Chromium 可访问性树、语义快照、axe 和键盘操作代理验证；本轮没有开启系统级 VoiceOver/NVDA 做语音输出逐句验收。当前已经存在会阻断真实读屏的已确认问题，修复后仍需用 VoiceOver 或 NVDA 对 Golden Path 做一次人工朗读回归。

## 一、结论

当前学生端在桌面视觉、桌面基本导航和减少动态效果方面已有良好基础，但尚不能通过完整的无障碍与移动端验收。主要阻断项不是“缺少一个 aria 属性”，而是五类系统性问题：

1. 全局图标按钮、表单控件和进度条存在无名称或无标签，屏幕阅读器无法说明用途。
2. 卡片、图谱连线、弹窗和部分自定义控件缺少完整键盘等价操作；资源预览弹窗没有接管焦点、没有焦点圈、Escape 也不能关闭。
3. 学情档案核心图表没有文本摘要或数据表，色弱/全色盲状态下多条折线主要依赖颜色区分。
4. 移动端存在三个确认的严重布局问题：AI 伴学在 390px 被侧栏挤成窄条；课程图谱搜索框变成巨型圆形；个人设置在 320px 出现文档级横向溢出。
5. 全站次要文本和控件颜色偏浅，自动扫描在 17 个页面发现对比度问题；共享课程工作区的灰色文本是主要来源。

已确认的优势：

- 17 条核心路由在 640px 宽度（1280px 桌面 200% 缩放的等效重排）没有文档级横向滚动。
- 7 条代表路由在 `prefers-reduced-motion: reduce` 下没有持续运行的动画。
- 课程图谱节点本身支持 Tab、Enter 和 Space，SVG 画布有整体名称；问题主要集中在连线、折叠关系和移动布局。
- 资源工坊 390px 主流程能正常单列重排，文字和主要按钮未被裁切。

## 三、按真实用户路径评审

### 1. 登录后全局导航：不健康

顶部通知按钮在 17 条路由均没有可访问名称；移动菜单按钮同样缺少稳定名称。页面也没有“跳到主要内容”的跳过链接，键盘用户每次换页都要重复经过整段导航。

修复范围：`ZyTopNav.vue`、全局布局和全局焦点样式。通知按钮应使用可读名称；移动菜单需要名称和展开状态；在布局首部增加跳过链接。

### 2. AI 伴学：桌面语义部分可用，移动端阻断

过程面板已有 `role="status"`，方向正确；但当前把整个对话线程设为 `aria-live="polite"`，流式逐字更新可能导致反复播报。应只播报开始、阶段变化、停止、完成和失败，最终回答完成后再播报一次摘要。主输入框、搜索历史输入、思考强度控件仍存在标签或键盘问题；页面还出现嵌套 `main` 地标。390px 下左侧历史栏占据大部分宽度，主对话被压缩为约一个汉字宽的纵向窄列，不能完成对话任务；复用该结构的练习批改和图像题解入口同样受影响。

由于当前约束是“不改 AI 伴学对话页”，本轮只记录，不实施。若该约束继续保留，则移动端 AI 伴学必须明确列为比赛演示限制；若目标是商业化移动端可用，则必须重新授权一个仅处理响应式的最小修复。

![AI 伴学 390px 布局阻断](../../../output/playwright/accessibility-2026-07-14/tutor-390.png)

### 3. 课程中心与课程工作区：基本可访问，交互语义不完整

课程卡、任务卡和资源卡以 `article + click` 实现，鼠标可用，但不是原生链接/按钮，也没有完整的键盘等价行为。课程中心在 390/320px 还会把“进入课程”CTA 和部分分类裁到右侧；因为父容器使用 `overflow:hidden`，文档宽度没有增加，自动横向溢出规则未能捕获。悬浮助手同时遮挡搜索和分类区域。课程工作区的返回、课程切换、页签和部分次要操作触控高度只有约 13–22px。图谱节点键盘支持较好，但可点击连线只有约 2–3px 高，且连线没有可访问名称，无法成为可靠的键盘/触控目标。

课程图谱在 640px、390px 和 320px 出现明显视觉错误：搜索输入区域被拉成大圆形，抢占首屏并破坏信息层级；路径节点在 390px 被压成单字，320px 只剩编号，已失去信息价值。源码存在相互覆盖的多轮响应式规则，前面启用的移动摘要/路径布局又被后续 `display:none !important` 压掉。移动端不应继续缩小桌面画布，建议默认显示节点列表/路径卡片，图谱画布作为二级入口。

![课程图谱 390px 搜索框异常](../../../output/playwright/accessibility-2026-07-14/graph-390.png)

### 4. 资源工坊：移动重排较好，表单与弹窗不合格

资源包生成主入口在 390px 能正常单列显示，主要流程仍可理解；但练习批改和图像题解入口复用了 AI 伴学的固定侧栏结构，在 390/320px 同样不可用。生成主入口的问题集中在：学习时长 `spinbutton`、增减按钮、部分选择器缺少名称；六个预览滚动区域不能通过键盘聚焦；预览弹窗打开后焦点仍停留在背景“预览摘要”按钮，按 Tab 会移动到背景“AI 复核”，Escape 后弹窗仍存在。该行为会让屏幕阅读器和纯键盘用户失去上下文。

修复要求：弹窗打开时聚焦标题或第一个操作；背景设为不可交互；焦点循环限制在弹窗；Escape 关闭；关闭后回到触发按钮。预览正文应能聚焦并提供区域名称。

![资源工坊 390px 重排](../../../output/playwright/accessibility-2026-07-14/workshop-390.png)

### 5. 学情档案与个人设置：视觉数据丰富，但无障碍等价信息不足

学情档案的标题层级基本清楚，但能力趋势、雷达、学习节律和资源偏好图在可访问性树中没有可读数据摘要，屏幕阅读器只能听到卡片标题。全色盲模拟下四条折线和图例明显趋同，资源偏好环图也难以辨别。能力趋势在 320/390px 将 12 周横轴文字全部强制显示，标签严重重叠；学习节律的纵轴最大值直接使用浮点加法，出现类似 `2.699999...` 的视觉文本。

建议共享 `Chart` 组件新增 `ariaLabel`、简短摘要和可折叠数据表入口；折线同时使用不同线型、符号或末端标签；移动端按宽度自动抽样横轴标签；节律纵轴最大值使用可控步长向上取整。

![学情档案 390px 横轴重叠](../../../output/playwright/accessibility-2026-07-14/portrait-390.png)

![学情档案全色盲模拟](../../../output/playwright/accessibility-2026-07-14/portrait-achromatopsia.png)

个人设置在 320px 的 `scrollWidth=323`，确认有 3px 文档级横向溢出；双列表单仍保持两列，输入内容被截断，悬浮“小智”还遮挡表单区域。

## 四、颜色与对比度

自动扫描中最常见的低对比组合：

- 顶部激活色 `#6366f1` 与近白背景约 4.43:1，刚低于普通文字常用阈值。
- 快捷键文字 `#94a3b8` 与 `#f1f5f9` 约 2.34:1。
- 课程工作区通用说明文字 `#8993a6` 与 `#fbfcff` 约 3.01:1，因共享组件在多页重复。
- 多处 `#98a2b3`、`#98a1b1`、`#8a95a8` 用作 12–14px 正文，不适合继续作为信息文本色。

不建议逐节点打补丁。应在现有设计系统中新增或收紧 `text-primary / text-secondary / text-muted / interactive-primary` token，再处理共享课程工作区、顶部导航和表单帮助文字。装饰性文字可以更浅，承载状态、说明和操作的信息文字不能继续使用装饰色。

## 五、触控目标与移动断点

响应式脚本执行了 17 条路由 × 28 个宽度，共 476 个“路由 × 宽度”组合；其中 464 个组合记录到至少一项候选问题。大量小目标来自同一共享控件在多个宽度重复出现，并非 464 个独立缺陷；另有一部分是组件内部输入节点，外层实际点击区域更大，需要人工复核。已确认需要修复的目标：

- 顶部导航图标按钮视觉高度约 22px。
- 课程工作区返回/课程切换按钮约 13px 高。
- 资源工坊“更多”等小按钮约 13–14px 高。
- 图谱连线交互热区约 2–3px 高。
- 多个页脚文字按钮约 14–15px 高。

建议工程底线为 24×24px；移动端主要操作和独立图标按钮优先 44×44px。图谱连线应使用透明粗描边扩大命中区，同时保留细视觉线。

## 六、修复决策建议

### 必须修：进入下一轮实施

1. **共享无障碍基础层**：全局可见焦点、跳过链接、顶部按钮名称、表单标签、进度条名称。
2. **核心键盘闭环**：课程/任务/资源卡改为原生链接或按钮；资源预览弹窗实现焦点接管、循环、Escape 和恢复；图谱连线命名并扩大命中区。
3. **图表等价信息**：共享图表组件支持名称、摘要和数据表；学情折线加入非颜色编码。
4. **移动端阻断项**：课程中心 CTA 裁切、图谱圆形搜索框/路径失效、个人设置 320px 溢出、学情横轴重叠。AI 伴学及复用其布局的练习批改/图像题解在 390px 不可用，需用户解除“不改”约束或授权仅响应式最小修复后才能实施。
5. **共享对比度 token**：优先修顶部导航、课程工作区和资源工坊，避免逐页覆盖。
6. **异步状态播报**：资源生成、下载、图谱刷新和 Agent 执行统一使用 `aria-live`/`aria-busy` 的产品化状态摘要，不播报模型原始思维链。

### 应修：P0 业务闭环完成后立即处理

1. 全站触控目标提升到工程底线，移动端主操作提升到 44px。
2. 首页页脚等非黄金路径控件补齐焦点样式和目标尺寸。
3. 课程图谱的折叠关系、筛选和 inspector 完整键盘操作。
4. 逐页减少低对比装饰文字，并建立自动回归阈值。

### 可延期

1. 非演示路径的像素级移动端美化。
2. AAA 对比度目标或所有图表的完整可交互数据探索。
3. 多种桌面屏幕阅读器的组合认证测试；当前先完成语义树和黄金路径人工朗读验收。

## 七、与比赛业务 P0 的排序关系

无障碍修复不能取代上一轮的五个业务 P0：统一 ResourceRun、后端课程图谱、实时 Agent 窗口、Word/PDF 生成前格式选择、真实 RAG 质量评测。建议顺序是：

1. 先用一个短周期完成共享基础层和三个非 AI 页面移动阻断项；这些修改范围集中，能防止后续页面继续复制错误。
2. 立即回到五个业务 P0，按同一 `run_id` 打通比赛 Golden Path。
3. 在每个业务 P0 交付时同步满足焦点、名称、状态播报和移动断点验收，不再把无障碍留到最后返工。
4. 业务闭环稳定后，完成全站对比度和触控目标第二轮收尾。

## 八、验收标准

下一轮修复不能以“页面看起来正常”为完成条件，至少满足：

- axe 核心规则在演示 Golden Path 中无 critical 命中；serious 命中逐项说明。
- 从地址栏开始只用键盘可完成：进入课程 → 打开资源工坊 → 生成/恢复资源 → 预览 → 下载 → 关闭并回到触发点。
- 弹窗/抽屉打开后焦点不进入背景；Escape 可关闭并恢复焦点。
- 学情核心数据在关闭 CSS/Canvas 或使用可访问性树时仍有等价摘要。
- 320/360/375/390/480/640px 不出现文档级横向滚动；核心文本不被压成单字列。
- 200% 等效重排下核心流程无双向滚动。
- 全色盲模拟下折线和状态不只依赖颜色。
- `prefers-reduced-motion: reduce` 下不出现非必要持续动画。
