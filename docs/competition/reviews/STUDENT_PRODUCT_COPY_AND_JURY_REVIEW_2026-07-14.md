# 学生端商业化文案与软件杯专家评审

日期：2026-07-14
范围：学生端全部主页面、用户可见文案、业务真实性、比赛完成度

## 一、评审角色与过程

本轮按五个角色交叉审查：产品经理、UX/内容设计师、高等教育学习体验专家、技术真实性审查员、中国软件杯评委。评审分为开场事实确认、逐页讨论、争议项辩论、共识排序和最终决策五个阶段。

共识：当前视觉完成度高于业务闭环完成度。继续增加页面或宣传词不会显著提分；必须把资源运行、图谱、实时 Agent、格式选择和 RAG 评测做成可重复证据。

## 二、本轮已修复

1. 学情档案删除“画像版本、证据数、可信度”等后台字段。
2. AI 伴学和思考过程用“查找资料、使用工具、组织回答”替代 RAG、MCP、系统初始化等工程术语。
3. 资源工坊隐藏 Agent 英文名、模型名、本地回退方式、文件清单内部名和原始质量日志。
4. 课程助手删除固定 94% 匹配度和虚构预计耗时。
5. 学习分析删除固定 4.8 小时和伪造七日柱状图，无数据时显示真实空态。
6. 个人设置不再默认实名认证、显示原始 UUID 或虚构最近活动。
7. 学生课程首页不再加载教师端作业提交率、平均分、资源流量和发布动态。
8. 全局错误提示不再暴露接口路径、端口、curl 或启动命令。

## 四、评分判断

按当前可提交证据保守估计：**约 65–70/100**。这不是视觉分，而是综合提交成熟度。

- 创新价值与实用性：概念完整，但真实闭环证据不足。
- 功能实现与技术要求：后端能力较多，主页面仍有旧链路和静态场景数据。
- 文档：本轮已建立框架，仍需加入架构图、数据图和真实案例。
- 视频与 PPT：尚未完成，不能提前计入高分。

## 五、达到高分区间的精确改进顺序

### P0-1：统一资源运行

资源工坊只使用一个 ResourceRun：SSE 显示真实步骤，支持取消、重试、刷新恢复；完成后数据库、文件、下载和课程资料页使用同一 run/package 记录。验收：浏览器录像 + 数据库行 + Word/PDF 实际文件。

### P0-2：后端课程图谱

学生图谱只读取课程图谱 API；节点状态和资源关系刷新后仍存在。验收：清空 localStorage 后页面不丢图；数据库可查询节点、边和资源关联。

### P0-3：统一实时 Agent 窗口

点击课程 Agent 后在当前页面打开实时窗口，显示可见行动、工具状态、产物和停止按钮，不再用提示词跳转冒充专用 Agent。验收：至少三个角色执行不同后端工具和输出结构。

### P0-4：格式选择与文件验收

生成前可选择 Word、PDF 或两者；生成后分别下载并打开。验收：文件类型、内容和排版均正确，权限下载测试通过。

### P0-5：RAG 质量评测

替换默认哈希 embedding；建立相关问题、跨章节问题、无关问题和越权问题集。验收：报告召回率、引用覆盖率、无关问题拒答率、首字延迟和失败率。

## 六、设计与无障碍限制

后续已完成屏幕阅读器语义树、键盘遍历、色觉模拟、200% 等效重排、减少动态效果和 17 条路由 × 28 个移动宽度测试。结果仍存在全局控件命名、键盘焦点、图表等价信息、对比度和三个移动端布局阻断项，因此不能声称达到完整无障碍合规。详见 [学生端无障碍、键盘与响应式深度审计](./STUDENT_ACCESSIBILITY_RESPONSIVE_AUDIT_2026-07-14.md)。
