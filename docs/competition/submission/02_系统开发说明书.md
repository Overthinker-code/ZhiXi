# 智屿系统开发说明书（初稿）

版本：0.1
日期：2026-07-14
范围：学生端主流程

## 1. 系统概述

智屿采用前后端分离架构。前端负责学生课程工作区、AI 伴学、资源工坊、学情档案和课程图谱；后端负责身份与权限、课程数据、对话编排、课程资料检索、资源文件生成、学习证据、画像计算、内容安全和持久化。

## 2. 技术架构

### 2.1 前端

- Vue 3、TypeScript、Vite、Vue Router、Pinia。
- Arco Design Vue 为主要组件体系；ECharts 用于画像与趋势图。
- MarkdownIt、Highlight.js、KaTeX 用于回答和学习内容渲染。
- SSE 用于对话与长任务事件展示；页面状态区分加载、成功、失败、空数据和降级。

### 2.2 后端

- FastAPI、SQLModel/SQLAlchemy、PostgreSQL、Alembic。
- MiMo OpenAI-compatible provider 负责当前大模型调用；讯飞模型接口保留配置入口，但未配置时不得在材料中写为已实测。
- 课程资料检索支持权限过滤、词法/向量检索与引用返回；当前默认哈希 embedding 属于降级配置，比赛演示前仍需切换并实测真实语义向量服务。
- 资源生成服务输出 Markdown、Word、PDF、导图、阅读清单、案例、讲解脚本和检查清单。

## 3. 核心业务链路

### 3.1 对话式学习画像

输入来自学生目标、课程进度、练习结果、提问与学习活动。`learning_report_service` 和 `user_memory_profile_service` 聚合学习证据，计算能力维度、薄弱点、学习偏好和建议。前端画像页仅显示对学生有意义的趋势、课程重点和行动建议，不直接显示画像版本、证据条数或内部置信度。

### 3.2 AI 伴学

学生提问后，系统先确定问题范围，再按需读取课程上下文、附件和检索结果。前端以“可见行动”方式展示查找资料、使用工具、组织回答等状态，并允许用户停止生成。回答区域支持 Markdown、公式、代码和引用。

### 3.3 个性化资源生成

资源工坊接收课程、知识点、目标、难度和时长。后台完成需求分析、资料查找、资源规划、内容生成、质量检查、文件整理与持久化。用户可预览并下载 Word、PDF 等文件。内部 Agent 名称、模型名和运行细节只进入日志与答辩证据，不直接暴露给学生。

### 3.4 学习路径与课程图谱

课程工作区提供任务、资料、图谱、学习分析和课程助手入口。后台已经存在课程图谱模型、迁移与服务；但当前学生图谱页仍有部分前端场景数据和本地状态，必须在最终提交前完成后端 API 接入与关系持久化验证。

## 4. 数据与持久化

- PostgreSQL 保存用户、课程、对话、资源包、资源运行、学习证据和课程图谱相关数据。
- Alembic 迁移包含资源包、ResourceRun、学习证据、课程图谱和节点操作等版本。
- 生成资源同时保存数据库记录和文件产物；下载前执行所有权与路径校验。
- 测试使用隔离的临时 PostgreSQL 数据库，不复用开发数据库。

## 5. 安全与防幻觉

- 身份认证、课程访问与附件访问执行服务端权限检查。
- 上传处理包含扩展名、MIME、大小、路径和内容边界检查。
- AI 接口具备请求预算、并发和超时控制；SSE 与 WebSocket 设置连接限制。
- 内容安全服务对输入和模型输出进行检查；资源生成包含安全复核。
- 无可靠课程来源时，产品应明确提示“按通用知识生成，建议结合课件复核”，不能伪造引用。

## 6. 性能与可用性

- 对话采用流式输出，区分首个有效内容延迟与完整生成耗时。
- 长任务展示真实阶段，避免长时间白屏。
- 前端共享请求适配层统一处理旧/新接口兼容、超时和用户错误提示。
- 生产启动脚本检查环境、数据库和服务健康；当前仍需继续缩小前端首屏包体。

## 7. 已验证事实与限制

### 已验证

- 前端 TypeScript 类型检查通过。
- 学生端测试脚本通过。
- 后端 256 项 pytest 通过，使用隔离 PostgreSQL 测试库。
- 学习画像页面已移除版本号、证据数、可信度等内部字段。
- 资源结果页已移除 Agent 英文名、模型名和本地回退细节。
- 学生课程首页不再展示教师端提交率、平均分和访问量。
