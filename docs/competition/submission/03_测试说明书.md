# 智屿学生端测试说明书

## 1. 测试目标

验证学生端主流程的功能正确性、数据真实性、权限边界、内容安全、文件可用性、性能和界面表达。测试结果必须区分“自动化通过”“浏览器已验证”“依赖外部模型未验证”和“仅有前端场景数据”。

## 2. 测试环境

- macOS，本地前端 `http://127.0.0.1:5174`
- FastAPI `http://127.0.0.1:8001`
- PostgreSQL `127.0.0.1:5432`
- 前端：Node.js + Vite
- 后端：`code/.venv` Python 环境
- 范围：桌面网页端；本轮不包含移动端适配结论

## 3. 自动化测试基线

| 范围 | 命令 | 2026-07-14 结果 |
| --- | --- | --- |
| 前端类型 | `npm run type:check` | 通过 |
| 学生端回归 | `npm run test:student` | 通过 |
| 后端 | `../.venv/bin/python -m pytest -q`（在 `code/backend`） | 300 passed |
| 生产构建 | `npm run build` | 通过 |
| 静态无障碍 | `node scripts/audit-student-accessibility.mjs` | 20 个目标文件，0 findings |

后端测试使用进程级临时测试数据库，测试结束后清理，不触碰开发数据库。当前仍存在 datetime、SQLModel 查询和测试密钥长度等警告，需在提交前逐步消除或记录风险。

## 4. 页面与文案测试

已用真实学生账号逐页检查 19 个实际页面，覆盖 AI 伴学、课程中心、资源生成、题库与小组、学情档案、个人中心、课程首页、课堂内容、任务、资料、课程图谱、学习分析和课程助手。测试脚本会校验最终 URL，避免把权限重定向页面误计为目标页面通过。

禁用词与泄露检查包括：画像版本、证据条数、可信度、后端、RAG、MCP、兼容入口、课程匹配度、资源包编号、回炉、固定预计耗时、模型名、Agent 英文名。最终 DOM 扫描未发现这些词出现在已检查页面的普通用户可见区域。
