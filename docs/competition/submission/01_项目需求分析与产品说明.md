# 智屿：个性化智能学习与资源生成平台

## 1. 项目定位

智屿面向高校学生，围绕“学什么、怎么学、用什么材料学、学得怎么样”四个连续问题，提供课程问答、动态学习画像、个性化资源生成、学习路径规划、课程图谱和效果反馈。项目选择数据库系统等计算机专业课程作为主要演示场景。

产品端坚持“结果面向学生、依据留在后台”：学生看到清晰的建议、资源和下一步行动；画像证据、来源、运行步骤、质量检查与模型调用信息保留在可审计链路中，供系统决策和答辩核验使用。

## 2. 目标用户与核心痛点

| 用户任务 | 现有痛点 | 智屿的处理方式 |
| --- | --- | --- |
| 理解课程难点 | 资料分散，无法判断回答是否贴合课程 | 按课程权限检索资料，输出带来源的回答 |
| 制定学习计划 | 计划依赖自觉，难随掌握情况变化 | 根据课程进度、练习和提问记录生成动态计划 |
| 获得适合自己的材料 | 通用课件难匹配基础、目标和偏好 | 多角色协作生成讲义、练习、导图、阅读、案例和脚本 |
| 发现薄弱点 | 只看到分数，不知道下一步做什么 | 将学习记录转成能力趋势、课程重点与可执行建议 |
| 持续复习 | 学习、资源、错题和图谱彼此割裂 | 课程工作区串联任务、资料、图谱、分析和课程助手 |

## 3. 赛题功能映射

1. **对话式画像**：从目标、课程、提问、练习与资源偏好中抽取不少于六个维度；前端仅展示能力趋势与行动建议，后台保存计算依据。
2. **多智能体资源生成**：覆盖讲义、练习、思维导图、拓展阅读、实操案例和讲解脚本等类型，并输出 Word、PDF、Markdown 等文件。
3. **个性化路径与推送**：根据当前课程进度和薄弱知识点生成学习顺序，并将资源放回课程学习场景。
4. **智能辅导**：支持流式回答、Markdown、附件、课程资料检索、引用和可中断过程。
5. **效果评估**：把练习评分、提问、学习活动转成后台学习证据，更新学情分析和后续建议。

## 4. 产品原则

- **真实优先**：无数据时展示空状态，不用固定分数或伪造进度填充页面。
- **可见行动**：生成、检索、检查和保存均给出用户可理解的过程状态。
- **过程可控**：长任务支持进度、错误说明、中断与重试设计。
- **最小暴露**：运行编号、Agent 英文名、模型名、内部置信度和原始推理不进入普通用户界面。
- **课程边界**：回答和资源明确绑定课程、用户权限与资料范围。

## 5. 当前产品范围

本阶段只提交学生端主流程。教师统计、课堂监控和数字人生产后台不作为学生端答辩主线，避免范围过大削弱核心闭环。
