# AI Coding 使用说明（初稿）

项目开发过程中使用 AI Coding 工具辅助代码检索、缺陷分析、方案比较、局部重构、测试编写、文档整理和浏览器回归。

## 使用边界

- AI 生成的代码必须经过人工审查、类型检查、自动化测试和浏览器验证。
- 密钥、账号、个人信息和生产数据不写入提示词或提交文档。
- 不把 AI 的推断当作实现事实；以仓库代码、数据库、文件和运行结果为准。
- 涉及第三方代码时，必须核对来源、许可证和保留声明。
- AI 不直接决定评分材料中的“已实现”状态，最终结论由测试证据确认。

## 典型用途

1. 审查学生端是否暴露内部模型、运行和画像字段。
2. 统一前端错误提示与产品文案。
3. 生成测试草案，再由开发者补充边界条件并运行。
4. 根据官方赛题要求建立文档结构和演示脚本。
5. 对多智能体、RAG、权限、安全和部署链路进行交叉审查。
