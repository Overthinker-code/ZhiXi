# 智屿 A3 智能体演示视频总脚本（录制执行版）

> 适用赛题：第十五届中国软件杯 A3「基于大模型的个性化资源生成与学习多智能体系统开发」<br>
> 正式成片：**6 分 42 秒**，不得超过 7 分钟<br>
> 核心验收：清晰展示系统操作流程、核心功能、多模态资源生成效果及前沿 AI 技术应用成果<br>
> 当前状态：脚本已确认，按 P0 门槛通过后执行录屏、配音与剪辑。

## 一、导演方案

### 1. 叙事主线

正式视频不按菜单机械巡展，而是跟随一名学生完成一次可验证的学习闭环：

**提出困难 → 基于课程资料答疑 → 图谱定位薄弱点 → 多智能体生成资源 → 预览与入库 → 完成练习 → 反馈回流画像 → 获得下一步路径。**

这条主线对应赛题的核心评分点：

- 对话式画像与个性化需求理解；
- 多智能体协作与至少 5 类资源生成；
- 个性化学习路径与资源推送；
- 智能辅导、练习反馈和学习效果评估；
- 流式输出、可见行动、生成进度、可预览下载与内容安全。

### 2. “所有页面都录”与“7 分钟以内”的处理

录制分为两层，但只交付一支 7 分钟以内的正式成片：

1. **全功能原始素材库**：逐页录制学生端所有真实页面、弹窗、预览和关键按钮，保留完整因果过程，用于剪辑、验收和答辩追问。
2. **正式比赛成片**：从原始素材中选取最能证明评分点的镜头，最终控制在 6:42。设置、消息、成就、小组等非核心页面只进入 2–3 秒产品全景蒙太奇，不挤占核心链路。

路由别名、历史重定向、异常页、教师端、数字人教师工具和静态营销页不属于学生端核心功能，不重复录制为产品能力。

### 3. 固定演示场景

- 演示账号：`student@example.com`（录屏不得显示密码）。
- 演示课程：数据结构。
- 核心知识点：栈的后进先出（LIFO）、入栈（push）与出栈（pop）；图谱定位节点为“栈与队列”。
- 固定提问：`我总是混淆栈的后进先出、入栈 push 和出栈 pop，30 分钟后要完成练习。请结合课程资料帮我安排学习顺序，并说明依据。`
- 资源目标：基础巩固，30 分钟，Word + PDF；输出讲义、分层练习、Mermaid 结构图、教学插图、5 秒动画、PPT、实操案例。赛题要求至少 5 类资源，正式录制须让其中至少 5 类均有可打开的真实内容。
- 练习设计：一题正确判断 LIFO 与 push/pop 的顺序，一题选择典型错误，用于展示解析、错题与画像回流。
- 图像题解素材：团队自制的栈操作题截图，确保版权清晰。

### 4. 多模态产物与提示词边界

- **Mermaid 结构图**：以确定性的 Mermaid 源码渲染栈的结构和操作序列，用于精确表达 LIFO、A/B/C 入栈和 C 先出栈；它不是 AI 生成图片或视频。
- **教学插图 prompt**：`16:9 教学插图，浅色简洁课堂背景，中央为一个竖直栈；橙、蓝、绿三个无文字方块由下至上叠放，顶部有一支绿色向下箭头和一支橙色向上箭头；不出现任何文字、数字、水印或品牌标识；画面左上与底部预留干净字幕区。A/B/C、push、pop 等准确标签由前端字幕或 Mermaid 确定性叠加。`
- **Seedance 5 秒动画 prompt**：`固定镜头，16:9，干净浅色教学背景和居中的竖直栈。橙、蓝、绿三个无文字方块依次从上方平稳入栈；随后绿色顶部方块先平稳出栈。全程无镜头移动、无切换、无文字、无数字、无水印、无品牌标识，底部保留字幕安全区，时长 5 秒。A/B/C 与操作名称由后期字幕叠加。`
- 教学插图与 5 秒动画仅作视觉补充，必须分别标注为“教学插图”“5 秒动画”；不得把它们冒充 Mermaid 结构图，也不得把 Mermaid 结构图冒充生成图片或视频。

4. **多模态能力实测**：至少完成并保存一次栈操作图片理解、Mermaid 结构图、教学插图、5 秒动画或 PPT 的产品内预览；缺少依赖或调用授权时，不得录制对应成功镜头。当前 Seedance 服务已完成真实提交验证，但账户返回 `insufficient_credits`，正式录制前须充值不少于一次任务所需的 50 credits 并重新生成；未通过前只能展示并明确称为“本地确定性栈动画”，不得称为 Seedance 云端生成。
5. **资源包真实性**：准备一条本轮真实完成的运行，至少含五类有正文/可视内容的产物和可打开的 Word/PDF；Mermaid、图片、动画和 PPT 必须分别标明真实类型；另准备一条 partial success/停止记录供故障兜底。
6. **图谱与反馈读回**：节点状态、资源关联、收藏、不感兴趣、练习提交和错题状态必须在刷新后仍存在；至少抽查 API、PostgreSQL 和文件三端一致。
7. **文案收敛**：在后台常驻任务未实现前，不使用“Profile Agent 持续运行”；错题专项练习若复用原题，不称“AI 生成全新同类题”。
8. **测试恢复**：修复当前学习画像前端契约回归，并完成后端、前端、真实浏览器点击链路测试；脚本中的每项能力都要有本轮运行证据。

## 五、数据、镜头与失败兜底

### 1. 录制数据包

- 固定数据库快照、固定学生账号、固定课程和固定演示日期；
- 一条带真实课程引用的 AI 回答；
- 一条完成资源运行、一个可恢复/停止运行、一个 partial success 运行；
- 至少五类栈学习资源及 Word/PDF，并含 Mermaid 结构图、教学插图、5 秒动画和 PPT 的已验证产物；
- 一道 LIFO/push/pop 正确题、一道典型错题、一张团队自制栈操作题图；
- 一条外部开放资源，链接在录制当天可访问；
- 学情画像的录制前后状态，以及推荐收藏/忽略后的刷新读回。

### 2. 失败处理规则

- 实时模型超过 12 秒仍无首个可见动作：保留真实等待 2 秒后切到同账号、同输入、同运行的已完成记录，画面标注“已完成运行回放”。
- 资源生成时间较长：可进行 2× 或 4× 缩时，但从点击生成到任务 ID、阶段状态、结果列表必须属于同一次运行。
- 外部链接失效：换用录制当天已核验的开放资源，不以截图伪装网页可访问。
- 某格式预览失败：该镜头退出正式版并登记缺陷，不用本地无关文件替代。
- 不允许跨账号、跨课程或跨运行拼接成一个“成功闭环”。

## 六、录制与剪辑规范

- 母版：2560×1440 或 1920×1080，16:9，30 fps；交付 1920×1080 H.264 高码率 MP4。
- 浏览器：统一 100% 缩放；固定窗口；隐藏书签栏、下载气泡、开发者工具、操作系统通知和任何账号/API 密钥。
- 鼠标：启用轻量点击高亮；指针到目标后停 300–500 ms 再点击；避免快速甩动和无意义来回滚动。
- 配音：48 kHz；先录干声再剪画面；整片约 -16 LUFS，峰值不高于 -1 dBTP。
- 字幕：简体中文，完整覆盖旁白；最多两行，每行约 16–20 个汉字；白字加深色半透明底，置于底部 8% 安全区上方。
- 转场：功能链内以直接切换、轻推近和匹配剪辑为主；不使用炫技转场掩盖加载、报错或跨运行。
- 音乐：只在片头与片尾低音量使用；功能操作段以旁白、点击声和必要的状态提示音为主。
- 片尾至少保留 2 秒 Logo 与项目名称，最终导出时长建议 6:38–6:45，绝不贴近 7:00。

## 七、最终验收表

正式录制前，为每个入选镜头填写：

`镜头编号 → URL → 操作 → API/任务 ID → 资源/文件 ID → 数据库或刷新读回 → 原始素材路径 → 是否允许进正片`

最终成片必须同时满足：

- 时长不超过 7 分钟；
- 能看清一次从输入到结果再到反馈的完整操作链；
- 至少 5 类个性化资源均有真实内容；
- 多模态输入或输出在产品内真实预览；
- 多智能体过程有职责、状态、产物和质量检查；
- Word/PDF 下载可打开，来源链接可访问；
- 画像和推荐只描述本轮有证据的更新；
- 不泄露密码、Token、模型原始推理、内部提示词和用户敏感信息；
- 不把静态场景数据、回退产物或旧录像包装成当前实时结果。
