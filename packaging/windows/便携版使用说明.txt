智屿智能教育平台 V1.0（Windows 64 位便携版）

1. 请先安装并启动 PostgreSQL。
2. 第一次双击“智屿.exe”会生成并打开 .env 配置文件。
3. 填写 POSTGRES_PASSWORD，以及你实际使用的 DeepSeek/阿里云百炼 API Key。
4. 保存 .env，再次双击“智屿.exe”。程序启动后会自动打开浏览器。
5. 默认访问地址：http://127.0.0.1:8001
6. 演示学生账号：student@example.com
   演示学生密码：student123456

注意：
- 必须保留“智屿.exe”、“.env.example”和“runtime”目录的相对位置。
- 本发布包不包含开发者真实密码、真实 API Key、聊天附件或运行日志。
- 首次启动会自动创建/升级数据库表，可能需要几十秒。
