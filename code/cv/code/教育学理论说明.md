# CV 课堂行为检测模块 —— 教育学理论框架说明

本文档说明 `educational_behavior.py` 及 YOLO 分析链路中使用的教育学理论、其在代码中的具体实现方式，以及对应输出的指标与可视化维度。

---

## 1. Fredricks 三维学习投入模型 (Three-Dimensional Engagement Model)

### 理论来源
Fredricks, J. A., Blumenfeld, P. C., & Paris, A. H. (2004). School engagement: Potential of the concept, state of the evidence. *Review of Educational Research*, 74(1), 59-109.

### 核心观点
学生的学习投入不是单一维度，而是由三个相互关联的维度构成：
- **行为投入 (Behavioral Engagement)**：可观测的身体参与，如出勤、举手、记笔记、眼神跟随
- **认知投入 (Cognitive Engagement)**：学习策略与心理努力，如深层加工、自我调节、知识整合
- **情感投入 (Emotional Engagement)**：兴趣、态度、归属感与情绪效价

### 代码实现
- 文件：`educational_behavior.py`
- 数据类：`EngagementDimension` (behavioral / cognitive / emotional)
- 个体画像：`StudentEngagementProfile`
  - `behavioral_engagement_index` (BEI)：基于头部姿态正直度、在席率、目标行为占比
  - `cognitive_engagement_index` (CEI)：基于布鲁姆层次映射、认知状态历史
  - `emotional_engagement_index` (EEI)：基于面部 blendshapes 嘴部/眉毛变化（expressiveness）
  - `learning_engagement_index` (LEI)：`0.35*BEI + 0.40*CEI + 0.25*EEI`
- 课堂群体报告：`ClassroomEngagementReport` 输出三维投入均值

### 前端展示
- 进度条：BEI / CEI / EEI / LEI
- 诊断建议：当某一维度明显低于其他两项时，自动生成针对性干预建议（如"情感投入偏低，建议嵌入情感锚点"）

## 2. Bloom 认知分类法修订版 (Revised Bloom's Taxonomy)

### 理论来源
Anderson, L. W., & Krathwohl, D. R. (Eds.). (2001). *A taxonomy for learning, teaching, and assessing: A revision of Bloom's taxonomy of educational objectives*. Allyn & Bacon.

### 核心观点
认知活动按复杂度分为六个层次：
1. **Remembering**（记忆）— 最低阶
2. **Understanding**（理解）
3. **Applying**（应用）
4. **Analyzing**（分析）
5. **Evaluating**（评价）
6. **Creating**（创造）— 最高阶

### 代码实现
- 枚举：`BloomLevel` (remembering / understanding / applying / analyzing / evaluating / creating)
- 姿态映射：`_map_to_bloom_level`
  - `head_pose == "down"` + `hand_position == "writing"` → **Applying**（记笔记是主动加工）
  - `gaze_direction == "front"` + `body_lean > 0.3` → **Analyzing**（身体前倾注视表示深度跟随）
  - `gaze_direction == "front"` + 轻微前倾 → **Understanding**
  - 单纯注视无前倾 → **Remembering**（被动接收）
- 课堂聚合：`generate_classroom_report` 统计全班布鲁姆层次分布

### 前端展示
- Bloom 认知分布条形图（remembering / understanding / analyzing / ...）
- 诊断建议：当低阶思维（remembering + understanding）> 70% 时，提示"高阶思维训练严重不足"

## 3. 持续性注意力动态模型 (Sustained Attention Dynamic Model)

### 理论来源
- 青少年持续性注意力的自然波动周期约为 **15-20 分钟**（文献支持的课堂注意力周期）
- 正常课堂注意力呈周期性波动，需区分"正常波动"与"异常脱离"

### 代码实现
- 常量：`ATTENTION_CYCLE_SECONDS = 900`（15 分钟一个周期）
- 相位判断：
  - `< 25%` 周期 → `peak`（注意力峰值）
  - `25%-50%` → `decline`（下降期）
  - `50%-75%` → `trough`（波谷期）
  - `> 75%` → `recovery`（恢复期）
- 趋势判断：
  - `mind_wandering_rate > 40%` → `crisis`（危机）
  - `mind_wandering_rate > 25%` → `declining`（下降）
  - `avg_lei > 0.75` → `rising`（上升）
  - 其他 → `stable`（稳定）

### 前端展示
- 注意力相位标签（peak / decline / trough / recovery / unknown）
- 注意力趋势标签（rising / declining / stable / crisis）
- 诊断建议：处于 `trough` 或 `declining` 时，建议切换教学模态或插入惊奇元素

## 4. 社会传染理论 (Social Contagion Theory)

### 理论来源
课堂中的分心行为具有空间聚集性与传染性，群体氛围会影响个体投入状态。

### 核心观点
- 如果分心学生在空间中聚集（相邻座位同时分心），可能是教学因素（社会传染）而非个体因素
- 低方差 + 普遍偏离注意力基线 = 高传染指数

### 代码实现
- 方法：`_calculate_contagion_index`
- 算法：
  - 计算全班注意力偏离度（`attention_deviation`）的标准差
  - `mean_dev < -0.2` 且 `std_dev < 0.25` → **高传染 (0.8)**：群体同步分心
  - `mean_dev < -0.1` 且 `std_dev < 0.35` → **中等传染 (0.5)**
  - 其他 → **低传染 (0.2)**：随机个体分心

### 前端展示
- 社会传染指数数值（0.00 - 1.00）
- 诊断建议：传染指数高时，提示"分心行为具有空间聚集性，建议调整座位或增加互动"

## 5. 认知状态推断与认知负荷窗口

### 理论来源
基于注意力动态模型与认知负荷理论，从可观测行为推断内在认知状态。

### 核心观点
- 认知投入不能直接用头部姿态衡量，需结合视线方向、手部动作、身体前倾等多维特征
- 区分"低头走神"与"低头看书/写字"是关键难点

### 代码实现
- 认知状态枚举：`CognitiveState`
  - `DEEP_PROCESSING`（深度加工）：身体前倾 + 注视前方/阅读
  - `PASSIVE_LISTENING`（被动听讲）：头部正直、无前倾、单纯注视
  - `SHALLOW_ATTENTION`（浅层注意）：轻微前倾或头部偏移
  - `MIND_WANDERING`（走神）：明显后仰、转头、视线游离
  - `TASK_SWITCHING`（任务切换）：看手机、交谈
  - `COGNITIVE_OVERLOAD`（认知过载）：长时间停顿、困惑姿态
- 手机二次判别：`decode_posture_education` 中增加几何启发式
  - `head_vertical > 0.10`（低头）
  - `wrists_below_face`（双手在面部下方）
  - `wrists_close`（双手水平距离 < 0.20，握持手机姿态）
  - → 自动修正 `raw_behavior` 为"查看手机"

### 前端展示
- 检测框颜色按认知状态区分：
  - 深蓝 = deep_processing
  - 亮绿 = passive_listening
  - 深橙 = shallow_attention
  - 红色 = mind_wandering / task_switching
- 个体认知状态标签（`cognitive_state`）

## 6. 时序画像与状态平滑

### 理论来源
单帧行为检测不确定性高，需要结合时序数据做平滑与验证。

### 代码实现
- 个体时序画像：`StudentEngagementProfile`
  - `behavior_history`：最近 128 帧行为事件
  - `cognitive_state_history`：最近 64 帧认知状态
- 状态平滑机制：
  - 注意力基线：使用前 1/3 历史数据的专注率作为个体基线
  - 异常下降标记：连续 3 帧偏离 < -0.2
  - 走神判定：结合时序频率，而非单帧姿态

### 前端展示
- 个体卡片：展示 LEI、BEI、CEI、EEI 时序累积值
- 走神预警：`mind_wandering` 标志 + ⚠️ 提示
