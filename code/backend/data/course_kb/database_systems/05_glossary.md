# 数据库系统术语表

- 主键（Primary Key）：唯一标识关系中元组的属性或属性组；在 PostgreSQL 中主键同时要求唯一和非空，并自动建立唯一 B-tree 索引。
- 外键（Foreign Key）：要求引用列的值能在被引用表的目标列中找到，用于维护参照完整性。
- 函数依赖：若属性集 X 的值确定属性集 Y 的值，记作 X → Y。它是规范化分析的核心关系。
- 第三范式（3NF）：对每个非平凡函数依赖 X → A，X 是超键，或 A 是主属性。3NF 通常在减少异常与保持依赖之间折中。
- BCNF：对每个非平凡函数依赖 X → Y，X 必须是超键，要求通常强于 3NF。
- ACID：原子性、一致性、隔离性和持久性的合称。
- MVCC：多版本并发控制，通过版本与快照规则决定事务可见的数据版本。
- B+树索引：适合等值与范围检索的平衡树索引结构；是否使用仍取决于代价估计。
- 执行计划：优化器选择的物理执行步骤，可通过 EXPLAIN 查看估算，通过 EXPLAIN ANALYZE 对照实际执行。
- WAL：预写式日志。相关日志先于数据页持久化，为崩溃恢复提供依据。
