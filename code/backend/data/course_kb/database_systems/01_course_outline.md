# 数据库系统原理课程大纲

## 学习目标

完成课程后，学生应能解释关系模型、使用 SQL 完成查询与数据定义、用函数依赖判断规范化结果、分析索引与执行计划，并能用事务和恢复机制解释并发故障。

## 六个学习单元

1. 关系模型：关系、元组、属性、候选键、主键和参照完整性。
2. SQL 基础：数据定义、连接、分组、子查询和约束。
3. 数据库设计：函数依赖、异常、1NF、2NF、3NF 与 BCNF。
4. 存储与索引：页、聚簇、B+树索引、代价与选择性。
5. 事务与并发：ACID、调度、锁、隔离级别与 MVCC。
6. 恢复：日志、先写日志、检查点、UNDO 与 REDO。

## 建议学习闭环

先完成概念前测，再阅读讲义；随后完成 SQL 或并发实验，通过带答案练习纠错，最后根据错题回到对应知识点。课程资料不足以回答实现版本或厂商差异时，应查阅对应数据库版本的官方文档，而不是把通用原理当作产品事实。
