# 第三章练习与参考答案

## 练习一：ACID 诊断

转账程序先扣除 A 的余额，随后服务崩溃，B 未入账。违反了哪一性质？

参考答案：首先暴露的是原子性问题，因为逻辑事务只完成了一部分。如果系统已向用户确认成功但重启后记录丢失，还同时涉及持久性。不能只凭“数据不对”笼统回答一致性；要指出失败发生在哪个事务边界。

## 练习二：不可重复读

事务 T1 连续两次读取同一账户余额，两次读取之间 T2 修改并提交，T1 得到不同结果。这是不可重复读。解决方案取决于业务：可以使用可重复读快照，也可以锁定目标行；若使用 Serializable，还需要处理序列化失败重试。

## 练习三：丢失更新

T1 和 T2 都读取库存 10，分别计算为 9 并写回，最终库存为 9 而不是 8。可采用原子更新 `UPDATE inventory SET stock = stock - 1 WHERE id = ? AND stock > 0`，或使用行锁、乐观版本号。选择方案时要同时验证受影响行数。

## 练习四：判断题

“MVCC 会自动避免一切并发异常。”错误。MVCC 改变读写冲突和可见性，但业务不变量、写写冲突、死锁与序列化重试仍需应用处理。

## 评分点

答案必须包含异常名称、发生条件、事务边界和至少一种可执行修复。只背诵 ACID 四个单词不给满分。
